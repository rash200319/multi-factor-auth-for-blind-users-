Create account

Enrol once, in order. You will register this laptop, then your phone, then (if you have one) a security key, then confirm a spoken security code.

How enrolment works

  1. Laptop — Windows Hello / fingerprint on this computer.
  2. Phone — scan a QR from Windows/Chrome (not drawn on this page). Use Bluetooth.
  3. Security key — USB/NFC key, or skip only for local testing if enabled.
  4. Spoken code — headphones on; hear a 6-digit code and type it back.
  5. Written recovery codes — save them once; used only if devices are lost.

Start or resume

Used to find your account later (resume enrolment or recovery). Not a password login.

Phone step — do this carefully

  1. Unlock your phone. Turn Bluetooth on for phone and laptop.
  2. Click Register phone below. A Windows/Chrome dialog appears (not a QR inside this webpage).
  3. If it says Insert security key, open More options → choose iPhone, iPad, or Android device.
  4. Scan the QR code with your phone camera / Google / Apple passkey prompt.
  5. Confirm on the phone with fingerprint or face unlock. Keep both devices nearby.
  6. If no QR appears on plain localhost, run node tools/tunnel.mjs (see tools/README.md), restart server + client, and try again over HTTPS.

Laptop step

Use this computer’s Windows Hello / fingerprint / PIN — not a USB key and not your phone yet.

Security key step

Insert a FIDO2 USB/NFC key and touch it when it flashes. No key? Use Skip security key (testing only) if your server has DEV_ALLOW_SKIP_SECURITY_KEY=true.

Confirm your security code

Put on headphones. We speak a 6-digit code (never shown on screen). Type it back to prove you heard it.

Your written recovery codes

Save these somewhere private. They are shown once. Use them only if laptop, phone, and security key are all unavailable.
