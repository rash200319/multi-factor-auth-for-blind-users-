Use a registered laptop or phone passkey. No password. Touch your fingerprint when prompted.

Which path do I use?

  1. Same laptop / phone as enrolment — use the button below.
  2. New laptop, phone still yours — still use Sign in; choose your phone passkey when Windows asks (same idea as Google’s other-device check).
  3. Laptop and phone both gone — try a security key on Sign in if you have one; otherwise open Recover account with email + written recovery code.
  4. Enrolment unfinished — open Create account → Resume unfinished enrolment.
